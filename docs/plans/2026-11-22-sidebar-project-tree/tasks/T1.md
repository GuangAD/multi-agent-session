# T1 agent 选择弹窗基建

> 依赖:无 | 对应:brief 第 2 节目标 ④、spec 覆盖标准 5 行

## 实现方式

ui-slice 把「新建会话菜单展开」布尔量整体替换为「弹窗描述」(可空对象:模式 + 目标项目):`openAgentDialog` 整体覆盖写入,`closeAgentDialog` 置空;不保留旧字段,不做合并。

`AgentPickerDialog` 是无 props 组件,开关、模式、目标项目全部读 ui-slice:描述为 null 或目标项目查不到(已被移除)时渲染 null。渲染时经 `bridge.agents.list()` 拉一次清单(失败仅控制台报错,弹窗内空列表)。模式分支:

- `new`(新建会话):标题「新建会话」,未安装的 agent 置灰不可点;点选后 `closeAgentDialog()` 并调 `openSession(目标项目, agent)`(sessions-slice 既有链路:入库 + 开标签 + fit 后 spawn)。若目标项目查不到,条目全部置灰并在弹窗内提示。
- `import`(导入历史会话):标题「导入历史会话」,不因未安装置灰(导入只读 agent 存储);点选后调 `importSessions(projectId, agentId)`,运行中禁用条目并禁止关闭(遮罩点击忽略,防误触中断观感),完成后把「已导入 N 条…」消息留在弹窗内,此时才允许关闭;弹窗不自动关。

弹窗骨架复用 ConfirmDialog 的遮罩风格(fixed inset-0 z-50 bg-black/40 + 居中面板);点遮罩与 Esc 关闭(import 运行中除外)。

`Sidebar` 挂载 `AgentPickerDialog`,同时删除 `<NewSessionMenu />`;`NewSessionMenu.tsx` 文件删除。`App.tsx` 的 Ctrl+N 分支改为:`setLeftOpen(true)` 后,仅当存在选中项目才 `openAgentDialog({ mode: 'new', projectId: 选中项目 id })`;effect 依赖数组同步替换。Esc 关闭用弹窗自身监听,不经 App 快捷键处理。

## 接口(伪代码)

落点:`src/renderer/src/store/ui-slice.ts`

```ts
// AgentDialogDescription / AgentDialogMode:定义见 spec.md 数据结构节,此处不改形状

// UiSlice:删除 newSessionMenuOpen / setNewSessionMenuOpen,新增:
agentDialog: AgentDialogDescription | null
openAgentDialog(dialog: AgentDialogDescription): void
  // 整体覆盖,不与旧值合并;无副作用与重入(幂等覆盖)
closeAgentDialog(): void
  // 置 null;未打开时调用保持 null,不抛错
```

落点:`src/renderer/src/components/sidebar/AgentPickerDialog.tsx`

```tsx
// 无 props;状态来源:ui-slice.agentDialog(开/模式/项目Id)、projects-slice.projects、sessions-slice
AgentPickerDialog(): React.JSX.Element | null
  // agentDialog 为 null → null
  // projects 中无 agentDialog.projectId → null(目标项目已被移除)
  // new 模式点选:closeAgentDialog() → openSession(project, agent)
  // import 模式点选:importSessions(projectId, agentId) → 消息留在弹窗内
```

落点:`src/renderer/src/App.tsx`(Ctrl+N 分支)

```ts
setLeftOpen(true)
if (selectedProject) openAgentDialog({ mode: 'new', projectId: selectedProject.id })
// 无选中项目:只展开左栏,不开弹窗
```

## 开发步骤

1. 写 `src/renderer/src/store/ui-slice.test.ts`:覆盖测试规格 5 条用例(期望来源:用例表)
2. 运行:`pnpm vitest run src/renderer/src/store/ui-slice.test.ts`;Expected: FAIL(exit 1),原因是 `agentDialog` / `openAgentDialog` / `closeAgentDialog` 尚未实现
3. 实现 ui-slice 新状态并删除旧布尔量(落点:`src/renderer/src/store/ui-slice.ts`)
4. 运行:`pnpm vitest run src/renderer/src/store/ui-slice.test.ts`;Expected: PASS(exit 0),5 条用例全绿
5. 新增 `AgentPickerDialog.tsx` 并挂到 `Sidebar`,删除 `<NewSessionMenu />` 与 `NewSessionMenu.tsx`
6. 改 `App.tsx` Ctrl+N 分支为 `openAgentDialog`,同步 effect 依赖数组,移除旧布尔量引用
7. 运行:`pnpm typecheck`;Expected: PASS(exit 0),无残留旧接口引用
8. 运行:`pnpm test`;Expected: PASS(exit 0),全量绿
9. 手动冒烟:`pnpm dev` —— Ctrl+N 选中项目时弹窗出现,选 agent 后会话入库、标签页打开;无选中项目时 Ctrl+N 只展开左栏;点遮罩/Esc 可关闭弹窗

## 测试规格

### 接缝 ui-slice 弹窗描述状态

| # | 输入 | 期望 | 期望值来源 |
|---|---|---|---|
| 1 | 初始 store | `agentDialog` 为 null | 约定(未开弹窗) |
| 2 | `openAgentDialog({ mode: 'new', projectId: 'p1' })` | `agentDialog` 深等于 `{ mode: 'new', projectId: 'p1' }` | 手算字面量 |
| 3 | 用例 2 后调 `closeAgentDialog()` | `agentDialog` 为 null | 约定 |
| 4 | `openAgentDialog({ mode: 'new', projectId: 'p1' })` 后再 `openAgentDialog({ mode: 'import', projectId: 'p2' })` | `agentDialog` 等于第二个描述(整体覆盖,不残留 `mode: 'new'`) | 手算字面量 |
| 5 | 初始 store 直接调 `closeAgentDialog()` | 仍为 null,不抛错 | 约定(幂等) |
