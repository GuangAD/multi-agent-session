# T2 侧栏项目树重构

> 依赖:T1(弹窗组件与 ui-slice 弹窗描述状态) | 对应:brief 第 2 节目标 ①②③、验收 7.1

## 实现方式

`Sidebar` 重构为两段:顶部「项目」标题行(左侧文字标签,右侧「+」图标按钮 = 既有 `addProject()`,系统目录选择框);下方项目列表(滚动区)。空态提示保留,文案改指右上角「+」。`AgentPickerDialog` 的挂载不动(仍在 Sidebar)。

`ProjectGroup` 项目行改为单行布局:chevron(展开向右/展开向下,随展开态翻转)+ 项目图标 + 名称(path 保留为副行小字,不丢信息)+ 右侧常驻两个图标按钮:「+」(新建会话)、「…」(更多)。点行本体 = `selectProject(id)` + 本地展开态取反,一次点击同时完成选中与展开/折叠;行上按钮 `stopPropagation`,不改变选中。展开态为组件本地 `useState`,默认展开;会话列表与「显示更多(N)」逻辑原样保留,仅外层多一层「项目展开」开关(项目折叠时会话列表整体不渲染)。

新增 `MoreMenu`:「…」点击弹出行内小面板(absolute 定位于按钮下方右对齐,面板外垫一层透明遮罩,点外部即关闭),两项:

- 「导入历史会话」→ `closeMenu` + `openAgentDialog({ mode: 'import', projectId })`
- 「移除项目」→ `closeMenu` + 既有 `removeProject(id)`(行为不变,无确认)

`ImportMenu.tsx` 删除,`ProjectGroup` 不再引用。会话行(`SessionRow`)与删除确认弹窗不动。

## 开发步骤

1. 重构 `Sidebar.tsx`:标题行 + 「+」= `addProject`,空态文案改指「+」,移除对新会话菜单的残留引用
2. 重构 `ProjectGroup.tsx`:chevron / 常驻「+」「…」/ 点行选中 + 展开切换 / 折叠时会话列表不渲染 /「显示更多」保留
3. 新增 `MoreMenu.tsx` 并接入「导入历史会话」(开弹窗)与「移除项目」
4. 删除 `ImportMenu.tsx`,清理引用
5. 运行:`pnpm typecheck`;Expected: PASS(exit 0)
6. 运行:`pnpm test`;Expected: PASS(exit 0),全量绿
7. 手动冒烟:`pnpm dev`,逐条过 brief 7.1 验收 —— 空态「+」添加项目;点行展开/折叠且选中跟随(文件树、Git 面板、VS Code 打开);行内「+」开新建弹窗建会话;「…」菜单导入开导入弹窗、结果显示弹窗内;移除项目生效;侧栏无常驻 agent 列表
