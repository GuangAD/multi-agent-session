# 侧栏项目树与 agent 选择弹窗 · 设计说明

> 2026-11-22 | 状态:草稿 | 档位:一页纸

## 1. 背景与问题

侧栏把「添加目录」「新建会话 + agent 列表」「每个项目的导入菜单」全部常驻铺开,纵向空间被菜单挤占,agent 列表在侧栏出现两份;项目行「点击选中」与「展开看会话」两个语义混在一起,层级表达不清。参考实现(用户提供的截图):顶部「项目」标题行 + 右侧「+」,项目行右侧常驻 chevron / … / +,会话缩进挂在项目下。

## 2. 目标 · 非目标 · 失败形态

**目标**

- 侧栏顶部「项目」标题行,右侧「+」按钮走系统目录选择框添加项目
- 每个项目行可展开/折叠,展开内容为该项目的会话列表
- 项目行常驻「+」(新建会话)与「…」(更多菜单)
- agent 选择(新建/导入)改为模态弹窗,侧栏不再常驻任何 agent 列表

**非目标**

- 不改主进程、IPC、store 数据结构与持久化格式
- 不改会话行(重命名/删除/状态点)的行为与外观
- 不动右侧面板、标签页、终端区
- 移除项目维持现状:直接移除,不加确认弹窗
- 展开/折叠态不持久化,启动默认全部展开
- 参考图中的分支行(「main」)、会话相对时间戳等元素不做

**失败形态**

- 布局重排后,文件树/Git 面板/「VS Code 打开」不再跟随选中项目(选中语义断了)
- Ctrl+N 变死键,或无选中项目时误开弹窗
- 弹窗能重复叠开或关不掉(开关状态跨组件错乱)

## 3. 选定方案

纯渲染层重排:重构 `Sidebar` 为「标题行 + 可折叠项目树」;新建一个 agent 选择弹窗组件,新建与导入共用、模式参数区分;ui-slice 的 `newSessionMenuOpen` 布尔量升级为「弹窗描述(模式 + 目标项目)」;删除 `NewSessionMenu` 与 `ImportMenu`。

被否:继续用内联展开菜单(用户明确要求弹窗化);「点行=选中、点箭头=折叠」分开(两次点击成本,且行上按钮已多)。

## 4. 约束

- 渲染层永不 import main,一切经 `ipc/bridge.ts`(AGENTS.md 工程边界)
- 视觉沿用现有 Tailwind zinc 色阶与 dark: class 策略,不引入新组件库
- 展开态是渲染层 UI 状态,不落盘(T6 既有约定)
- 目录名用具体领域名,不设 utils/helpers;注释中文、JSDoc 风格

## 5. 关键决策

- 点项目行 = 选中 + 切换展开/折叠,一次完成 [你]
- 「更多」菜单 = 「导入历史会话」「移除项目」两项 [你]
- 项目默认全部展开;项目内会话超 8 条仍走「显示更多(N)」 [你]
- Ctrl+N = 有选中项目时打开「新建会话」弹窗,无选中时不动作 [你]
- 新建与导入共用一个弹窗组件,模式区分标题与提交行为 [我]
- 弹窗开关、模式、目标项目放 ui-slice(Ctrl+N 在 App 全局按键处理里触发,与弹窗本体不在同一组件分支,沿用现状经 store 共享的模式) [我]
- 新建模式未安装 agent 置灰,导入模式不置灰(导入只读 agent 存储,不依赖本机安装) [我]
- 项目行上的「+」「…」阻断冒泡,不改变选中;弹窗的目标项目显式传入,不依赖选中态 [我]
- 导入结果消息显示在弹窗内,弹窗不自动关 [我]
- 项目展开态为组件本地状态,不落盘(与 T6 会话级展开态一致) [我]

## 7. 验收标准

### 7.1 验收条目

- 无项目时:见「项目」标题行与空态提示;点「+」弹系统目录选择框,选中目录后项目入列
- 点项目行:展开/折叠会话列表,同时该项目成为选中项,文件树/Git 面板/「VS Code 打开」跟随
- 项目行「+」:打开「新建会话」弹窗,选 agent 后建会话并开标签页(现有链路不变)
- 项目行「…」:展开更多菜单;「导入历史会话」打开导入弹窗,选 agent 后扫描,结果显示在弹窗内;「移除项目」行为与现状一致
- Ctrl+N:有选中项目时打开新建弹窗;无选中时不动作
- 侧栏中不再有任何常驻 agent 列表

### 7.2 测试接缝

ui-slice 的弹窗描述状态(设值/清空语义)是唯一纯逻辑接缝,沿用 zustand slice 同目录测试先例;其余为 UI 装配,靠 typecheck + 手动冒烟覆盖。

## 8. 授权项

- 弹窗视觉细节(宽度、内边距、遮罩),与现有 ConfirmDialog 同风格即可
- 图标选型:标题行「+」、项目行「+」「…」、更多菜单项的具体 lucide 图标
- 「更多」菜单的实现形态(行内绝对定位小面板,或轻量 popover)
- 「显示更多(N)」按钮与展开 chevron 的具体样式
- 会话列表缩进层级与间距微调
