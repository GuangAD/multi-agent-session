# T1 侧栏行视觉与交互调整

> 依赖:无 | 对应:brief 第 2 节全部目标、spec 覆盖标准 1-5、7.1 全部验收条目

## 实现方式

改两个渲染组件。

**ProjectGroup**：删掉 import 里的 `Folder` 与项目行的 `<Folder>` 元素；chevron 折叠、「+」新建会话、「…」更多菜单全部不动。

**SessionRow**：删掉 import 里的 `Pencil` 与 `RUN_STATE_DISPLAY`（行尾点不再渲染）、`Button` 仍供删除按钮使用。

- 行首：在 `AgentBadge` 之前按 `runState === 'working'` 条件渲染一个 `LoaderCircle`（lucide 现成图标）加 `animate-spin` 类；其余态与 `runState` 缺省不渲染。
- 行尾：删除原 `runState && <span …圆点…>` 整段；标签内的状态完全由行首动画承担。
- 标题改名：把 `<button onClick={onOpen}>` 内包住徽标/标题/状态的主体改为——标题文字元素上挂 `onDoubleClick` 进入 `startEditing`；单击仍走 `onOpen`，但用短延迟（约 200ms）触发，双击到达时 `clearTimeout` 取消打开并进入编辑，避免单击先打开会话。`editing` 分支的输入框与 `commit`/`Escape` 逻辑保持原样（Enter 提交、Esc 取消、空名不提交）。删除按钮与 `onClick={onDelete}` 不动。
- 上下 padding：行容器 `<li>` 的 class 在现有 `px-1` 基础上增加 `py-1`（或同等量级），列表项间距 `space-y-0.5` 不动。

定时器用 `useRef<ReturnType<typeof setTimeout> | null>` 保存，组件卸载时 `clearTimeout`，防止卸载后误触发 `onOpen`。

## 接口(伪代码)

落点:`src/renderer/src/components/sidebar/SessionRow.tsx`

```
SessionRow({ session, runState?, active, onOpen, onRename, onDelete }): JSX
  // props 形状不变（定义见 spec.md 数据结构节：本特性无数据结构变更）
  openTimer = useRef<ReturnType<typeof setTimeout> | null>(null)
  // 副作用与重入：openTimer 是单例 ref，每次单击先 clear 再重设；卸载清理
  effect(() => () => clearTimeout(openTimer.current), [])

  startEditing(): void   // 既有：draft = session.title; editing = true
  commit(): void         // 既有：editing = false; trim 非空且变更 → onRename(title)

  scheduleOpen(): void
    clearTimeout(openTimer.current)
    openTimer.current = setTimeout(() => onOpen(), 200)
  cancelOpen(): void
    clearTimeout(openTimer.current); openTimer.current = null

  render 行首: runState === 'working' ? <LoaderCircle class="animate-spin …" aria-label="工作中" /> : null
  render 主体: 徽标 + <span onDoubleClick={startEditing}>{title}</span>
  render 行尾: 删除按钮（保留）；无状态点、无铅笔
```
