# T1 xterm 补丁重放

> 依赖:无 | 对应:brief 第 2 节、spec 的 T1 覆盖标准

## 实现方式

**干什么**:把 Orca 对 xterm 6.1.0-beta.336 的根级补丁引入本项目,经 pnpm 补丁机制重放,消除 Viewport NaN 毒化与渲染回调自我排队两处上游缺陷。

**输入**:`.reference/orca-1.4.265/config/patches/@xterm__xterm@6.1.0-beta.336.patch`(只读快照)、根 package.json。

**处理**

1. 补丁文件拷入仓库补丁目录
2. package.json 的 pnpm 段登记 patchedDependencies 映射
3. `pnpm install` 触发重放
4. 重放验证 + 全量检查 + 实机冒烟

**失败与退出**:重放冲突即停手报告(预期不会发生,版本号与 Orca 完全一致);冒烟发现渲染行为差异按 brief 第 6 节未定项 1 单点评估,不影响本任务结构。

## 接口(伪代码)

不适用——本任务无新增代码接口,只落配置与产物。

## 开发步骤

1. 拷贝补丁:`.reference/orca-1.4.265/config/patches/@xterm__xterm@6.1.0-beta.336.patch` → `config/patches/@xterm__xterm@6.1.0-beta.336.patch`
2. package.json 的 `pnpm` 段加 `patchedDependencies: { "@xterm/xterm@6.1.0-beta.336": "config/patches/@xterm__xterm@6.1.0-beta.336.patch" }`
3. 运行:`pnpm install`;Expected: 补丁重放输出无冲突报错,exit 0
4. 验证重放落地:`grep -c "hasMeasuredCellHeight" node_modules/@xterm/xterm/src/browser/Viewport.ts`;Expected: ≥ 1(补丁源码段标记存在),且 `node_modules/@xterm/xterm/lib/xterm.js` 与 npm 原始发布内容不一致
5. 运行:`pnpm typecheck`;Expected: exit 0,node、web 两投影均无错误
6. 运行:`pnpm test`;Expected: 全部既有用例绿,用例总数与改动前基线一致(改动不增删用例)
7. 实机冒烟(用户配合):多开 3 个以上终端来回切换 + agent 持续输出 → 无空白等待、无整窗冻结;滚动正常;中文输入法输入正常;主题切换与 emoji 行无回归
8. 记录冒烟结果,交 controller 验证与提交
