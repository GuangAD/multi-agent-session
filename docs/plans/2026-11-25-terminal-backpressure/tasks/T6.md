# T6 WebGL 回退重挂

> 依赖:无 | 对应:brief 第 2 节、spec 的 T6 覆盖标准

## 实现方式

**干什么**:GPU 上下文丢失降级 DOM 后不再永久降速——该终端标记丢失,下次激活时尝试重挂 WebGL,失败保持 DOM。

**输入**:WebGL addon 的 `onContextLoss` 事件;`activateTerminal` 的激活时机。

**处理**

1. 丢失路径:现有 `onContextLoss → dispose` 之后,给该会话打丢失标记
2. 激活路径:`activateTerminal` 时若有标记,尝试加载新的 WebGL addon
3. 成功 → 清标记回到 WebGL 渲染;抛错(无 WebGL2/驱动拒绝)→ 吞掉,标记保留,继续用 DOM
4. 每次激活至多尝试一次,不做重试风暴

**失败与退出**:重挂失败是常态路径(驱动不可用),静默保持 DOM;标记随会话关闭一并清理。

## 接口(伪代码)

落点:`src/renderer/src/components/terminal/use-terminal.ts`(扩展,无新文件)

```ts
// TerminalEntry 扩展(内部字段,定义见 spec.md 数据结构节)
// webglLost?: boolean

activateTerminal(sessionId): void
  // 用途:转可见 + fit + 聚焦(既有);本任务追加「丢失则重挂一次」
  // 怎么用:既有调用方不变;重挂仅在标记存在时发生,成功清标记,失败保留
  // 出错时:重挂抛错吞掉,保持 DOM 渲染,不影响 fit 与聚焦
```
