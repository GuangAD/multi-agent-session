# T5 隐藏后台 fit

> 依赖:T4(体验承接;单测不硬依赖) | 对应:brief 第 2 节、spec 的 T5 覆盖标准

## 实现方式

**干什么**:窗口尺寸稳定后,把全部隐藏终端按「假如可见」的网格尺寸分帧重设,并经既有链路同步 PTY,消除切回后的宽度过时。

**输入**:窗口 resize 事件(经稳定门收敛);可见终端的格子度量(参照)。

**处理**

1. 稳定门:resize 抖动合并,静默期(200ms 量级)后判定稳定,只回调一次
2. fit 本体:无可见终端时跳过该轮;否则以可见终端的格子像素为参照
3. 遍历隐藏终端,按参照度量与目标盒子宽高换算目标网格,直接重设
4. 分帧:每帧至多处理一个终端,RAF 排空
5. 隐藏判定与 PTY 同步沿用既有路径(display 检查、onResize → pty:resize),不新开测量

**失败与退出**:重设失败(终端已销毁等)单点吞掉,不影响其余终端;无可见参照时静默跳过,等下一轮窗口稳定。

落点:`src/renderer/src/components/terminal/stable-resize-gate.ts`(新文件)

```ts
createStableResizeGate(options: { quietMs: number; onSettled: () => void }): {
  notifyResize(): void // 抖动期间反复调用,只在静默期满后回调一次
  reset(): void // 清计时器,测试收尾
}
  // 用途:把高频 resize 收敛成「布局已稳定」单次信号
  // 怎么用:resize 处理器里只调 notifyResize;onSettled 回调内不得再调 notifyResize(自触发)
  // 出错时:不抛错;timer 注入,fake timers 驱动
```

```ts
fitHiddenTerminals(): void
  // 用途:对全部隐藏终端按假想网格重设,消除后台宽度过时
  // 怎么用:由稳定门 onSettled 触发;内部自行分帧,可重入安全(上一轮未排空时忽略新触发)
```

## 测试规格

### 接缝 createStableResizeGate(模块行为)

穷举抖动合并与稳定判定;timer 注入。

| # | 输入 | 期望 | 期望值来源 |
|---|---|---|---|
| 1 | 三次 notifyResize 间隔 < 静默期 | 静默期满后 onSettled 恰一次 | 手算 |
| 2 | 静默期满后再次 notifyResize | 再次触发一次 onSettled | 手算 |
| 3 | reset 后推进时间 | 零回调 | 约定 |

### 接缝 fitHiddenTerminals(页面接线)

只验证 fit 本体的过滤、换算与分帧;稳定门已在上接缝测全。

| # | 输入 | 期望 | 期望值来源 |
|---|---|---|---|
| 4 | 一可见一隐藏,触发 fit | 仅隐藏终端被 resize,可见不动 | 约定 |
| 5 | 参照度量 cols=X 时隐藏终端目标宽 | resize 参数 = 假想网格换算值 | 手算 |
| 6 | 全部终端隐藏(无参照) | 整轮跳过,零 resize | 约定 |
