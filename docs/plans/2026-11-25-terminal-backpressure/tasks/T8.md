# T8 文件预览样式跟随设置

> 依赖:无 | 对应:spec 的 T8 覆盖标准;来源 = 门 2 后用户补充(原 TODO.md 留痕移入)

## 实现方式

**干什么**:文件预览的文本区不再写死样式,字体族/字号/字重取设置中的终端外观配置,设置变更后已打开的预览即时跟随。

**输入**:store 的 `settings`(经既有 `useSettings` selector)。

**处理**

1. `FilePreview` 用 `useSettings` 订阅设置,经 `resolveTerminalAppearance` 解析出 `fontFamily` / `fontSize` / `fontWeight` 三项——与终端同一解析来源,不出现第二处字体解析(项目既有约束:字体度量单一来源)
2. 三项以 inline style 应用到文本区 `<pre>`,替换原写死的 `text-xs`
3. `useSettings` 是 store 订阅:设置变更自动重渲染本组件,inline style 即时生效,无需额外接线
4. 头部文件名/提示文字的 `text-xs` 保持不动——只改文本区正文的阅读样式

**失败与退出**:无错误路径;`terminalFontFamily` 缺省时解析函数已兜底默认回退链(既有行为)。

## 接口(伪代码)

无新增导出。落点:`src/renderer/src/components/file-panel/FilePreview.tsx`(样式接线)

```tsx
const settings = useSettings((s) => s) // 既有 selector,store 变更自动重渲染
const appearance = resolveTerminalAppearance(settings) // 字体三项的唯一来源

<pre style={{ fontFamily: appearance.fontFamily, fontSize: appearance.fontSize, fontWeight: appearance.fontWeight }} ...>
```
