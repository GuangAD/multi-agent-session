# T7 预览与终端共存渲染

> 依赖:无 | 对应:brief 第 2 节、spec 的 T7 覆盖标准;来源 = 门 2 后用户报障,debugging 根因:TerminalTabs 预览分支卸载 TerminalView(违背 ADR-0002)

## 实现方式

**干什么**:激活文件预览时终端实例不再被卸载——保持挂载、仅隐藏,scrollback 与 TTY 状态全程保留,消除切回后的内容截断、双 TUI 与滚动错乱。

**输入**:store 的 `previewActive`(预览激活态)、`activeTabId`。

**处理**

1. TerminalTabs 渲染结构调整:终端组(`tabs.map` 出的 TerminalView)移出预览的条件分支,**始终渲染**
2. 预览激活时终端组整组 `display:none`,预览组件照常渲染在终端区位置;预览关闭恢复显示
3. TerminalView 的激活语义收窄为「标签激活 **且** 预览未激活」——由 TerminalTabs 在传参处计算,TerminalView 本体零改动
4. 激活语义变化自动带动既有行为:预览激活时该终端不 fit/不聚焦;预览关闭恢复激活时走既有 `activateTerminal`(fit + 补发 ready + 聚焦)

**失败与退出**:无新错误路径;预览打开期间 PTY 数据照常入队(T4 落地前为直灌现状),实例常驻后不再有暂存袋兜底场景。

## 接口(伪代码)

无新增导出。落点:`src/renderer/src/components/terminal/TerminalTabs.tsx`(渲染结构)、`TerminalView.tsx`(不改本体,仅入参语义变化)。

```tsx
// 渲染结构(示意,保持既有组件与 props 不变)
tabs.map((tab) => (
  <TerminalView
    key={tab.sessionId}
    active={tab.sessionId === activeTabId && !previewActive} // 语义收窄:预览激活即视为非激活
    ...
  />
))
{previewActive && previewPath !== null ? <预览组件/> : tabs.length === 0 ? <空态/> : null}
// 预览与终端并存的视觉互斥由终端组整组 display:none 实现(TerminalView 已按 active 控制 display)
```
