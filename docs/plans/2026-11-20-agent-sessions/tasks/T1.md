# T1 骨架与项目持久化

> 依赖:无 | 对应:brief 第 2 节目标 1/5、spec 覆盖标准「接缝 storePersistence」

## 实现方式

以 @quick-start/create-electron 模板(base + react-ts 两层合并)为起点:主进程持有 store 领域模块(原子读写)与 projects IPC 域;渲染层三栏空壳(左栏项目列表、中间终端占位、右侧面板占位,左右均可收起),Zustand projects 切片经 bridge 调 IPC;目录选择用系统对话框(主进程弹)。store 含 projects/sessions/settings/ignoreList 四段,本任务只真正使用 projects 与 settings,其余先建空段。所有类型进 shared。

## 接口(伪代码)

落点:`src/main/session-store/store-persistence.ts`

```ts
DEFAULT_STORE: AppStore                       // 非接缝,只读常量
loadStore(file: string): Promise<AppStore>
  // 调用形状:读文件 → JSON.parse → 缺字段补默认 → 失败则把原文件改名 <file>.corrupt-<ts> 后返回 DEFAULT_STORE
  // 错误行为:任何解析失败都不抛出,走损坏兜底
saveStoreAtomic(file: string, store: AppStore): Promise<void>
  // 调用形状:序列化 → 写 <file>.tmp → rename 覆盖
  // 副作用与重入:每次调用整体覆盖,无累积
```

落点:`src/main/ipc/channels.ts` + `src/main/ipc/projects.ts`、`src/preload/index.ts`、`src/renderer/src/ipc/bridge.ts`、`src/renderer/src/store/projects-slice.ts`

```ts
projects:list / projects:add / projects:remove   // 通道名与 shared/ipc-contract 一一对应
addProject(): Promise<Project>                    // 主进程弹目录选择框 → 归一化路径 → 去重(同路径不重复入库)→ 落盘
```

## 开发步骤

1. 并入模板:base + react-ts 两层合并进仓库根(模板取 `pnpm dlx` 安装的 @quick-start/create-electron 包内 `template/`);改 package.json(name=agent-sessions,engines node 24,packageManager pnpm,scripts 增 `test: vitest run`);补 devDependencies:zustand、tailwindcss、@tailwindcss/vite、vitest、lucide-react
2. 建 vitest.config.ts(environment node,include `src/**/*.test.ts`);Expected:`pnpm vitest run` 报 `no test files found`(基座空,允许,此步只验证配置可加载,exit 1 属预期)
3. 写测试:storePersistence 五条用例(见测试规格;期望来源:手算与构造反例)
4. 运行:`pnpm vitest run src/main/session-store/store-persistence.test.ts`;Expected: FAIL(exit 1),`5 failed`,红因是 loadStore/saveStoreAtomic 尚未实现
5. 写最小实现(落点:`src/main/session-store/store-persistence.ts`,AppStore 定义落 `src/shared/types.ts`)
6. 运行:`pnpm vitest run src/main/session-store/store-persistence.test.ts`;Expected: PASS(exit 0),`5 passed`,且不是 `0 passed`
7. 接线:channels/projects IPC + preload bridge + projects-slice + 三栏空壳与左右栏收起按钮(Tailwind class 策略先按跟随系统)
8. 运行:`pnpm typecheck`;Expected: PASS(exit 0),两投影无错误
9. 运行:`pnpm vitest run`;Expected: PASS,`5 passed`
10. 手动冒烟(交用户):`pnpm dev` 出三栏窗口 → 添加目录 → 重启列表仍在
