# T10 Git 面板

> 依赖:T1 | 对应:brief 第 2 节目标 4、spec 覆盖标准「接缝 parseStatusPorcelain / parseDiffLines」

## 实现方式

`git-service` 以 simple-git 封装 status/diff/stage/unstage/commit/branches/checkout(有状态:按项目 root 缓存 repo 句柄),porcelain 与 diff 行解析抽成纯函数供单测;`git:*` IPC 暴露。渲染层 GitPanel:变更文件列表(暂存/未暂存分组)、选中文件渲染 unified diff(增删行着色)、按文件暂存/取消暂存、提交框(显示当前分支)、分支下拉切换。不做 push/pull/rebase。

## 接口(伪代码)

落点:`src/main/git-service.ts`

```ts
parseStatusPorcelain(raw: string): GitStatus
  // 纯函数:解析 porcelain v1 输出;空输出 → 空列表;R 码拆新旧路径
parseDiffLines(raw: string): Array<{ type: 'added' | 'removed' | 'context' | 'other'; text: string }>
  // 纯函数:逐行分类
gitService.for(root: string): { status(); diff(); stage(); unstage(); commit(); branches(); checkout() }
  // 副作用与重入:按 root 缓存句柄,同 root 复用;commit 返回摘要哈希
```

落点:`src/main/ipc/git.ts`、`src/renderer/src/components/git-panel/{GitPanel,StatusList,DiffView,CommitBox}.tsx`

## 测试规格

### 接缝 parseStatusPorcelain / parseDiffLines(模块行为)
porcelain 样例字符串逐条解析。

| # | 输入 | 期望 | 期望值来源 |
|---|---|---|---|
| 1 | ` M a.ts` | unstaged=m | git porcelain 文档(外部参照) |
| 2 | `?? b.ts` | 未跟踪条目 | 同上 |
| 3 | ` D c.ts` | 标记删除 | 同上 |
| 4 | `R  old.ts -> new.ts` | 新旧路径拆分 | 同上 |
| 5 | `MM d.ts` | staged 与 unstaged 并存 | 手算 |
| 6 | 空字符串 | 空数组,branch 仍解析 | 手算 |
| 7 | `## main...origin/main [ahead 1]` | current=main | 手算 |
| 8 | `+foo` | added | 手算 |
| 9 | `−bar`(及 `-bar`) | removed | 手算 |
| 10 | ` 上下文行` | context | 手算 |
| 11 | `@@ -1,2 +3,4 @@` | other | 手算 |
| 12 | 空字符串 | 空数组 | 约定 |
