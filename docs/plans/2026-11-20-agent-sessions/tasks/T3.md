# T3 PTY 注册表与会话终端

> 依赖:T2 | 对应:brief 第 2 节目标 1、spec 覆盖标准「接缝 buildSpawnArgv / samplingTap」

## 实现方式

主进程 pty-registry 管 PTY 全生命周期:spawn(按定义构造命令、cwd=项目目录)、字节流转发(单会话独占流,经 `pty:data` 推渲染层)、write/resize、kill(单杀)与应用退出 killAll(全量清理,不留孤儿)。采样落盘开关用环境变量 `AGENT_SESSIONS_SAMPLE=<目录>` 开启,开启时把字节流原样追加写入 `<目录>/<sessionId>.bin`,供 M3 采样。渲染层每会话一个常驻 xterm 实例(容器持 Map,tab 切换仅切换可见性),scrollback 取 settings(默认 10000);本任务会话先为内存态(TabSession),T4 落库持久化。xterm 依赖本任务引入:@xterm/xterm、@xterm/addon-fit;node-pty 列入 electron.vite main external。

## 接口(伪代码)

落点:`src/main/pty-registry.ts`

```ts
buildSpawnArgv(def: AgentDefinition): string[]
  // 纯函数:别名归一后取规范命令;argv = [command]
samplingTap: { enabled(): boolean; wrap(id: SessionId, stream: EventEmitter): void }
  // 副作用与重入:每会话创建一个追加写句柄,kill 时关闭;enabled 取决于环境变量
ptyRegistry.spawn(p: { sessionId: SessionId; def: AgentDefinition; cwd: string }): void
ptyRegistry.write(id: SessionId, data: string): void   // 未知 id 静默忽略
ptyRegistry.resize(id: SessionId, cols: number, rows: number): void
ptyRegistry.kill(id: SessionId): void                  // 杀进程并删条目;exit 事件照常发出
ptyRegistry.killAll(): void                            // 全量清空;应用退出时调用
  // 副作用与重入:内表 spawn 增、kill 删、killAll 清空
```

落点:`src/main/ipc/pty.ts`、`src/renderer/src/components/terminal/{TerminalTabs,TerminalView}.tsx`、`src/renderer/src/components/terminal/use-terminal.ts`、内存会话表 `src/renderer/src/store/sessions-slice.ts`(本任务先内存态)
