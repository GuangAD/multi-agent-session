# T4 会话记录与侧栏

> 依赖:T3 | 对应:brief 第 2 节目标 2、spec 覆盖标准「接缝 sessionRecords」

## 实现方式

会话记录从内存态转正为持久化:`session-records` 领域模块持有全部 CRUD(操作 store 的 sessions 段,经 saveStoreAtomic 落盘,防抖合并连续写),`sessions:*` IPC 补齐 rename/remove/open/list;渲染层侧栏渲染项目分组下的会话行(含运行中标记 = 有活动标签页),新建会话改为「入库 + 开标签页」,重开 = 原样拉起(resume 在 T8 接入);删除走确认弹窗,记录有活动标签页时连带关闭;重命名只改显示名。T3 的内存 TabSession 改为挂接到持久记录 id。

## 接口(伪代码)

落点:`src/main/session-store/session-records.ts`

```ts
sessionRecords.create(store: AppStore, p: { projectId; agentId }): Session

sessionRecords.rename(store, p: { id; title }): void      // 只改 title,其余字段不动

```
