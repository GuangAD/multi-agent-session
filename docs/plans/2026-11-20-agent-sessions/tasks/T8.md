# T8 回填与自动续接

> 依赖:T4、T6 | 对应:brief 第 2 节目标 2、spec 覆盖标准「接缝 BackfillCoordinator / resumeArgv」

## 实现方式

BackfillCoordinator 管「待回填资格」:同一 agent + 项目目录同时只有一个会话持有资格(先开者持有,其关闭或回填成功时释放,后开者接棒);持有者按节流轮询(750ms 起,逐级放慢至 15s 封顶,照抄 Orca 节流)扫描该 agent 存储的新会话文件,发现即把 id(及转录路径)写回记录并停止;imported 会话永不参与;轮询到头无果则放弃,记录保持无 id。`resumeArgv` 五家参数照 Orca `agent-resume-argv.ts` 原文实现:claude `[--resume,id]`(可选 effort 不做)、codex `[resume,id]`、agy `[--conversation,id]`、pi `[--session,filePath]`(无 filePath 返回 null)、kimi `[--session,id]`。重开链路接入:记录有 id 且定义支持续接 → 跑 resume 拉起;无 id 或 imported → 原样拉起;禁止双开:点击已运行会话 = 聚焦现有标签页(前端与 IPC 双重拦截)。
