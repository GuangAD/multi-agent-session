# T9 文件浏览

> 依赖:T1 | 对应:brief 第 2 节目标 4、spec 覆盖标准「接缝 shouldIgnore / scanTree」

## 实现方式

主进程 `fs-tree` 扫描项目目录为树(忽略 .git/node_modules/dist/.reference/out 等固定清单,遵守 .gitignore 后置不做),`file-content` 单句柄完成大小检查、二进制探测(前 N 字节嗅探)与有界读取,超限截断并标记;`files:*` IPC 暴露。渲染层右栏 FileTreePanel(树,懒展开)+ FilePreview(只读文本,截断提示),右栏收起能力沿用 T1 布局;手动刷新按钮。文件预览对不支持预览的类型(二进制等)提供「通过 VS Code 打开」按钮;另提供「通过 VS Code 打开项目目录」:优先 code 命令(复用 PATH 探测),未装 VS Code 时回退系统默认应用。
