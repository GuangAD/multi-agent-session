# T1 主进程插件化迁移

> 依赖:无 | 对应:brief 第 2 节全部目标的主进程半边、spec 覆盖标准 1/2/3/5、7.1 依赖方向达标

## 实现方式

五个 agent 各建一个自包含插件包(`src/main/agents/plugins/<id>/ `):`plugin.ts`(定义对象:meta + 状态规则 + 图标 SVG 字符串 + 品牌色 + sessions 挂接)、`scan.ts`(扫描器,自 session-import 迁入)、随包 helper、`__fixtures__/` 与 `<id>.test.ts`(fixture 回放,自 session-import 迁入,`import.meta.dirname` 相对定位在迁移后仍成立)。迁移映射:

- claude:`claude.ts`(scan)、`claude-project-dir-encoding.ts`、`claude.test.ts`、`__fixtures__/4b0c9d2e-*.jsonl` 等本 agent fixture
- codex:`codex.ts`(scan)、`codex-rollout-files.ts`、`codex.test.ts`、本 agent fixture
- pi:`pi.ts`(scan)、`pi.test.ts`、本 agent fixture
- kimi:`kimi.ts`(scan)、`kimi.test.ts`、本 agent fixture
- antigravity:`antigravity.ts`(scan)、`antigravity.test.ts`、本 agent fixture

包内 import 调整:扫描器对 SDK(agent-home / path-match / runtime-path-separators)的引用改为指向 `../../session-store/session-import/` 的新相对路径;`plugin.ts` 以相对引用挂接 `./scan`。session-import 的 `__fixtures__` 中五个 agent 的转录样本随各自测试迁走;`state-parser` 的采样 fixture 留守(agent-state 零改动)。

插件清单:`src/main/agents/plugins/index.ts ` import 五个插件包并 `agentRegistry.register([...])`;`agent-registry.ts ` 删除对具体定义的 import 与登记(注册表本体行为不变)。

定义契约变化(shared/agents.ts):`AgentId ` 开放为字符串(shared/types.ts);`AgentDefinition.icon ` 改为**可选**(完整 SVG 文档字符串)、新增 `color ` 品牌色字段。图标来源 = 插件包内 `icon.svg ` 文件(约定落点),`plugin.ts ` 经 SDK helper `pluginIcon(import.meta.dirname)` 读取(存在返回文档字符串、缺失返回 undefined);打包后 asar 对 readFileSync 透明。五个插件包的 `icon.svg ` 从渲染层定稿图形生成:claude `#d97757` 星芒 / codex `#0284c7` 结环(simple-icons 加 fill)/ pi `#059669` 三方块 / antigravity 官方全彩原样(自带 defs/滤镜,根节点 `fill:none` 内联)/ kimi `#1783ff` K+蓝点(重出字形版,非旧方块文件)。

依赖反转:`runImport ` 入参改为携带 `scan`(可选)与 `agentId`——编排不再 import agentRegistry;无 scan 时返回 `{ imported: 0 }` 语义不变。组合点在 IPC 层:`ipc/sessions.ts ` 导入 handler 从注册表取插件并把 `sessions?.scan ` 注入;`ipc/pty.ts ` 本就是组合层,仅确认其扫描器获取不直接 import 扫描器文件。`run-import.test.ts ` 的打桩形态随之改写(不再 stub agentRegistry,直接注入扫描函数;既有用例口径与期望值来源不变)。

守卫强化(`scan-wiring.test.ts `):既有「注册表全部插件挂 scan / resumeArgv」守卫改写延续(真实注册表、不 mock,遍历 `agentRegistry.list() ` 而非硬编码五 id);新增静态断言:session-import 生产文件(非 .test.ts)不得 import `agents` 域。

渲染层本任务零改动:`AgentId ` 开放为字符串后,现有 `Record<AgentId, …> ` 映射自动兼容,行为与视觉不变。

## 开发步骤

1. 建 `src/main/agents/plugins/ ` 骨架,按迁移映射逐包迁文件(测试内相对 import 同步修正)
2. 生成五个 `icon.svg `(定稿图形 + 各自固定色 fill;kimi 重出 K+蓝点字形版);写 `plugin-icon.ts ` helper;五个 `plugin.ts ` 改写:`icon: pluginIcon(import.meta.dirname)`、新增 color、sessions 挂 `./scan`
3. 写 `plugins/index.ts ` 清单装载;`agent-registry.ts ` 删除具体定义 import 与登记
4. shared 层:`AgentId ` 开放为字符串;`AgentDefinition ` icon 语义变更 + `color ` 字段
5. `runImport ` 依赖反转;`run-import.test.ts ` 打桩形态改写;`ipc/sessions.ts ` 组合点注入
6. `scan-wiring.test.ts `:守卫遍历改为 `list()`;新增反向依赖静态守卫用例
7. 从 `ipc/agents.ts ` 抽取 `buildAgentListItem ` 纯函数并补单测
8. 运行:`pnpm typecheck`;Expected: PASS(exit 0)
9. 运行:`pnpm test`;Expected: PASS(exit 0),全量绿——含随迁的五个扫描器 fixture 回放
10. 运行:`grep -rn "from '.*agents/agent-registry'" src/main/session-store/session-import --include="*.ts" | grep -v test`;Expected: 无输出(反向依赖守卫的运行时复核)
