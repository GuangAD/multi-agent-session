# T3 验收用假 agent 冒烟

> 依赖:T1、T2 | 对应:brief 7.1 第一条验收(新增 agent = 插件包 + 一行登记)

## 实现方式

临时新增一个验收用假 agent 插件(冒烟后移除,不留在仓库):

- 插件包 `src/main/agents/plugins/demo-smoke/`:`plugin.ts` 定义——id `demo-smoke`、显示名「冒烟用例」、command `cmd`(Windows 必存在,安装探测必过)、**不提供 icon.svg**(顺带验证缺失兜底路径)、品牌色任意、状态规则走 degraded 降级(有输出 = working、退出 = exited、安静 2 秒 idle)、`sessions.scan` 返回一条固定假候选(cwd 指向真实项目路径以便匹配)、`resumeArgv` 返回 null(续接降级路径)
- `plugins/index.ts ` 登记一行

`pnpm dev ` 手动冒烟五环(逐条记录结果):

1. **列表 + 缺失兜底**:弹窗出现「冒烟用例」且以「品牌色 + 首字母」兜底砖显示(该插件无 icon.svg),安装态为已安装(cmd 存在)
2. **安装探测**:同上(cmd 命中即探测环节通过)
3. **状态点**:对 demo 会话发一条命令产生输出 → 绿色 working;静置 2 秒 → 灰色 idle
4. **新建会话**:demo 会话可建、标签页打开、cmd 可交互
5. **导入 + 续接降级**:导入动作扫出 1 条假候选入库;重开该会话按「不支持续接」原样拉起

冒烟后移除:插件目录与登记行一并撤出,`git status ` 恢复干净(仅本任务产物不入库);全量测试重跑确认绿。

## 开发步骤

1. 写 demo 插件包 + 清单登记一行
2. 运行:`pnpm typecheck`;Expected: PASS
3. `pnpm dev ` 手动五环冒烟(逐条记录;人工步骤,不得虚构结果)
4. 移除 demo 插件目录与登记行;`git status ` 干净
5. 运行:`pnpm typecheck && pnpm test`;Expected: 双绿

## 测试规格

无单测接缝——本任务本质是端到端人工验收(brief 7.1 第一条),GUI 链路无自动化接缝,预登记 waiver;五环冒烟结果逐条记入 `plan.md ` 开发记录,未验证项如实标注。
