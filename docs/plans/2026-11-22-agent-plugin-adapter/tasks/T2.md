# T2 渲染层载荷驱动

> 依赖:T1(载荷携带 icon SVG 字符串与品牌色) | 对应:brief 第 2 节「渲染层载荷驱动」目标、spec 覆盖标准 4、7.1 渲染层条目

## 实现方式

新增 `src/renderer/src/store/agents-slice.ts ` 并入 app-store:`agents: AgentListItem[] `(默认空数组)+ `loadAgents()`(经 `bridge.agents.list() ` 装载,失败仅控制台报错并保持空数组)+ `agentById(agentId)` 查找:命中返回载荷项,查无返回兜底描述(`{ def: { id, name: agentId, icon: '', color: '' }, installed: false }` 形态,图标与配色的兜底处理交给徽标组件)。

`App.tsx ` 启动 effect 增加一次 `loadAgents()`(与 loadProjects/loadSessions 同段)。

`agents-display.tsx ` 泛化:`AgentBadge ` 改为 `{ icon?: string; color?: string; name?: string; size?: number }`——icon 非空时经 data URL(`data:image/svg+xml;utf8,` 编码)交给 `<img>`(品牌图标均为固定自配色);icon 缺失时渲染**首字母兜底砖**:圆角底 + 名称首字母,已知 agent 用品牌色(底取低透明度、字母取实色),完全未知 agent 用中性 zinc 同款。组件不持任何按 id 的映射表;调用方从 store 载荷取 icon/color/name 传入(查无 → 全缺省)。

`AgentPickerDialog.tsx `:删除本地 `useState + bridge.agents.list() ` 装载,改读 store 的 `agents`(装载由 App 启动完成);对话框内安装态置灰、选择逻辑不变。

`SessionRow.tsx `:经 `agentById(session.agentId) ` 取载荷,把 `def.icon`/`def.color`/`def.name ` 传给 `AgentBadge`;未知 agent 全缺省,天然走中性兜底砖。

删除 `src/renderer/src/agents-icons.tsx `(五枚品牌 SVG 已以字符串形态迁入主进程插件包,渲染层不再持有)。

## 接口(伪代码)

落点:`src/renderer/src/store/agents-slice.ts`

```tsx
AgentsSlice {
  agents: AgentListItem[]            // 默认 []
  loadAgents(): Promise<void>        // bridge.agents.list();失败保持 [] 不抛
  agentById(id: string): AgentListItem | undefined  // 纯查找,未知返回 undefined
}
```

落点:`src/renderer/src/agents-display.tsx`

```tsx
AgentBadge({ icon?, color?, name?, size? = 20 }): React.JSX.Element
  // icon 非空 → <img src={toDataUrl(icon)}>;缺失 → 首字母兜底砖(color 实色/低透明底)
  // 无任何按 id 的映射表
```

## 开发步骤

1. 新增 `agents-slice.ts` 并挂入 app-store(装载 / 查找)
2. `App.tsx ` 启动 effect 增 `loadAgents()`
3. `agents-display.tsx ` 泛化:icon data URL / 首字母兜底砖双形态;删除 `AGENT_COLORS ` 与按 id 映射
4. `AgentPickerDialog.tsx ` 接 store;`SessionRow.tsx ` 经 `agentById ` 传 icon/color
5. 删除 `agents-icons.tsx`;全局清理残留引用
6. 写 `agents-slice.test.ts`(测试规格 3 条)
7. 运行:`pnpm typecheck`;Expected: PASS(exit 0)
8. 运行:`pnpm test`;Expected: PASS(exit 0)
9. 手动冒烟:`pnpm dev ` —— 五 agent 徽标与弹窗显示正常、与迁移前一致(留证;渲染细节属人工步骤)
