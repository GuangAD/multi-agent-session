# T3 注入器与五家配置合并

> 依赖:T1、T2 | 对应:spec 模块划分(merge/、injector、pi 模板)、brief 失败形态 1/5、覆盖标准 2

## 实现方式

`merge/claude-settings.ts`(接缝):操作对象 = 项目 `.claude/settings.json` 文本。`apply(text, managed: { event, command }[])` → 新文本:JSON.parse(失败 → 原样返回 = fail-closed);managed 条目追加进 `hooks.<event>` 数组;**认领** = 条目 command 含本应用脚本文件名的稳定子串(`forwarder.mjs`,不用完整路径——防安装位置/版本漂移导致旧条目失认成重复);重复 reconcile 先认领后插,幂等;`remove(text)` → 仅摘认领条目,空数组/空 hooks 键清理。用户已有条目**语义保留**为硬断言口径:parse 后用户子树 deep-equal(JSON 重序列化不改语义,不做字节级文本保真——与 TOML 的 marker 方案区分,登记为口径裁决)。

`merge/hooks-json.ts`(接缝):codex `.codex/hooks.json` 与 antigravity `.agents/hooks.json` 两个分支(形状以 `.tmp/hook-docs/` 官方原文快照为准,实施时逐字段对照);同 apply/remove/幂等/fail-closed 口径。

`merge/kimi-toml.ts`(接缝):marker 块方案,从 `.reference/orca-1.4.265/src/main/kimi/kimi-hook-config-toml.ts` 裁剪移植(文件头标注 Ported/MIT):start/end 注释包住 managed `[[hooks]]` 表;认领 = 表内 command 指向本应用脚本;摘除只删 marker 区间;TOML 间隙/未知多行结构 **fail-closed 原样返回**(保用户字节);用户自有 `[[hooks]]` 原样保留(字节级)。

`injector.ts`(编排,冒烟):`reconcile()` = 脚本落盘(forwarder-script 写盘,node 路径经 `resolveCommandPath('node')`)→ 遍历 store 已添加项目 × 有 `hooks` 声明的插件 → 按 kind 分发 merge(项目级四家)→ kimi 全局 config.toml 一次;`ensureProject(projectPath)` = 该项目配置存在性快校验 + 缺则补(spawn 前自愈);`removeProject(projectPath)`(项目删除联动,ipc/projects 接线)与 `removeAll()`(hooks:remove IPC,preload 同步)。

pi:`plugins/pi/extension-template.ts` 模板字符串 → 写盘 `<project>/.pi/extensions/soloport-state.ts`;内容 = 订阅 spec 映射的 pi 事件、读 `process.env` 三令牌、直接 fetch POST(不经 forwarder 脚本)、失败静默;存在即覆盖(带版本注释)。

## 接口(伪代码)

落点:`src/main/agent-hooks/merge/*`

```ts
// claude-settings / hooks-json:语义保留口径(文本进、文本出、fail-closed)
applyClaudeSettings(text: string, managed: { event: string; command: string }[]): { text: string; changed: boolean }
removeClaudeSettings(text: string): { text: string; changed: boolean }
applyHooksJson(kind: 'codex' | 'antigravity', text: string, managed: /* 同上 */): { text: string; changed: boolean }
removeHooksJson(kind: 'codex' | 'antigravity', text: string): { text: string; changed: boolean }
// kimi-toml:字节保留口径(marker 区间外的文本逐字节不动)
applyKimiToml(text: string, managed: { event: string; command: string }[]): { text: string; changed: boolean }
removeKimiToml(text: string): { text: string; changed: boolean }
```

落点:`src/main/agent-hooks/injector.ts`

```ts
reconcile(): Promise<void>          // 启动全量
ensureProject(projectPath: string): Promise<void>   // spawn 前自愈
removeProject(projectPath: string): Promise<void>   // 项目删除联动
removeAll(): Promise<void>          // hooks:remove IPC(kimi 全局含内)
```

## 开发步骤

1. 三个 merge 接缝 + 全分支用例(kimi-toml 从 Orca 移植,逐行 diff 核对)
2. extension-template.ts 模板与写盘
3. injector 编排 + ipc/projects / ipc/hooks 接线 + preload
4. `pnpm typecheck` + `pnpm test`;Expected: PASS
5. mutation check ≥2 条留痕(认领条件改宽 → 用户条目被误删转红;marker 摘除边界改错 → 用例红),均还原全绿

| # | 输入 | 期望 | 期望值来源 |
|---|---|---|---|
