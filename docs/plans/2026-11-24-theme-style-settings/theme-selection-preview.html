你选定的 10 套。每张卡是用本项目的 10 个语义 token 渲染的迷你界面;下方色条从左到右: base / panel / surface / line / ink / inkMuted / accent / onAccent / hover / accentHover。
色值来源:VS Code 与 GitHub 四项取自 .reference 里 Orca 规范化的主题 JSON(字段一一对应); Carbonfox / Selenized White 取自各自官方色值;Tango Dark / Light、Gruvbox Light (hard) 取自仓库 src/shared/themes/catalog.ts(Gruvbox 仅背景换官方 hard 档)。
两处按你的指定覆盖:GitHub Dark 主色 → #0078d4,GitHub Light 主色 → #000000,卡片上已标出。
