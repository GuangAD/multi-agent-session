# T1 语义 token 层落地(不改行为)

> 依赖:无(前置重构) | 对应:brief 第 2 节目标 4、spec 数据结构节 token 落地

## 实现方式

**干什么**:把渲染层界面颜色从硬编码 Tailwind 调色板类收敛为语义 token 变量,默认灰两形态 = 现状观感,全应用观感迁移前后一致。

**输入**:现有组件中的 zinc/neutral/white 颜色类;button 等组件的深浅配对写法。

**处理**

1. 新建 `theme-tokens.css`:`:root` 写浅色默认灰变量,`.dark` 覆盖深色值;同时定义 `--foreground`、`--muted-foreground` 别名指向语义变量(scrollbar-sleek.css 既有引用接上,不改其结构)。
2. `main.css` 增加 Tailwind 4 `@theme inline` 映射,生成语义 utility。
3. 按目录迁移组件类:ui → sidebar → terminal 壳(TerminalTabs 等,不碰 terminal.css)→ git-panel / file-panel / App.tsx。
4. 状态语义色(green/red/amber 等非主题色)保留原样,不迁移。

**失败与退出**:纯样式替换,无运行时失败路径;迁移遗漏由第 8 步残留扫描与冒烟清单兜住。

## 接口(伪代码)

落点:`src/renderer/src/assets/theme-tokens.css` + `src/renderer/src/assets/main.css`

无模块导出。token 基准值(默认灰,来源:现状 zinc 组合逐对核对):

| token | 浅(:root) | 深(.dark) |
|---|---|---|
| base | #ffffff | #18181b |
| surface | #ffffff | #27272a |
| line | #e4e4e7 | #3f3f46 |
| ink | #18181b | #f4f4f5 |
| inkMuted | #52525b | #d4d4d8 |
| accent | #18181b | #f4f4f5 |
| onAccent | #fafafa | #18181b |
| hover | #e4e4e7 | #27272a |
| accentHover | #3f3f46 | #d4d4d8 |

utility 映射见 spec 数据结构节(`bg-base`、`bg-surface`、`border-line`、`text-ink`、`text-ink-muted`、`bg-accent`、`text-on-accent`、`hover:bg-hover`、`hover:bg-accent-hover`)。

类迁移映射表:

| 旧写法(浅 + dark: 深) | 新写法 |
|---|---|
| `bg-white dark:bg-zinc-900`(窗口根) | `bg-base` |
| `bg-white dark:bg-zinc-800`(面板/浮层) | `bg-surface` |
| `border-zinc-200 dark:border-zinc-700` | `border-line` |
| `text-zinc-900 dark:text-zinc-50/100` | `text-ink` |
| `text-zinc-600 dark:text-zinc-300/400` | `text-ink-muted` |
| `bg-zinc-900 text-zinc-50 dark:bg-zinc-100 dark:text-zinc-900`(主按钮) | `bg-accent text-on-accent` |
| `hover:bg-zinc-700 dark:hover:bg-zinc-300`(主按钮悬停) | `hover:bg-accent-hover` |
| `hover:bg-zinc-200 dark:hover:bg-zinc-800`(ghost 悬停) | `hover:bg-hover` |

个别组件存在表中未列的配对时,按「同一 token 的浅深 zinc 值」就近归位;拿不准的记录到开发记录,不得静默发明第四种色。

## 开发步骤

1. 建 `theme-tokens.css` 写入上表变量与 `--foreground`/`--muted-foreground` 别名。
2. `main.css` 加 `@theme inline` 映射。
3. 迁移 `components/ui/` 四个文件。
4. 迁移 `components/sidebar/` 组件(含 MoreMenu)。
5. 迁移 `components/terminal/` 壳组件(TerminalTabs 等)。
6. 迁移 `components/git-panel/`、`components/file-panel/`、`App.tsx`。
7. 残留扫描:`grep -rn "zinc-" src/renderer/src --include="*.tsx"` 与 `grep -rn "neutral-\|bg-white" src/renderer/src --include="*.tsx"`;Expected: 均为 0 处。
8. 运行 `pnpm typecheck`;Expected: exit 0,0 error。
9. 运行 `pnpm test`;Expected: exit 0,全绿,通过条数与开工基线一致(基线数值由实施者开工时记录并写进开发记录)。
10. 冒烟 `pnpm dev`:浅/深三态循环切换,观感与迁移前一致;终端区、滚动条、文件面板、git 面板无半深半浅块。
