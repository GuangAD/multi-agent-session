# T6 设置对话框

> 依赖:T2、T3、T4、T5 | 对应:brief 第 2 节目标 1、7 与即时生效语义;spec 覆盖标准(无新接缝,手动冒烟)

## 实现方式

**干什么**:新增设置对话框(外观 + 通用两区),MoreMenu 加入口;全部控件改动即时生效、即时落盘。

**输入**:settings-slice 的全量设置;主题/字体清单(T3、T4 数据)。

**处理**

1. ui-slice 增加 settingsDialogOpen/openSettingsDialog/closeSettingsDialog;App 根部挂 SettingsDialog(打开时 loadSettings 兜底刷新)。
2. 外观区:界面主题深/浅下拉(APP_THEMES 的 name)、终端主题深/浅下拉(TERMINAL_THEMES 键,按深浅两组排列)、字体下拉(TERMINAL_FONT_OPTIONS)、字号(8~32)、字重(细 300/常规 400/中粗 500)、行高(1.0~2.0 步 0.1)、光标样式(方块/竖线/下划线)、光标闪烁开关。
3. 通用区:默认 Shell 下拉(cmd/powershell/pwsh)、回滚行数数字(1000~50000)。
4. 每个控件 onChange 直接 updateSettings(单字段 patch);数字控件设 min/max 属性,夹紧交给主进程;「完成」按钮只关闭。

**失败与退出**:落盘失败不回滚显示(slice 既有策略);对话框 Esc / ✕ / 完成三种方式关闭。

## 开发步骤

1. ui-slice 增加开合状态与动作。
2. SettingsDialog 壳:遮罩 + 面板 + 完成/Esc/✕ 关闭。
3. AppearanceSection 全部控件(下拉数据分别接 APP_THEMES、TERMINAL_THEMES、TERMINAL_FONT_OPTIONS)。
4. GeneralSection 两个控件。
5. MoreMenu 增加「设置」项(Settings 图标),onClick 派发 openSettingsDialog 并 onClose。
6. App.tsx 挂载 SettingsDialog。
7. 运行 `pnpm typecheck`;Expected: exit 0。
8. 运行 `pnpm test`;Expected: exit 0,全绿。
9. 冒烟 `pnpm dev`(逐项,全部要求即时生效且重启保持):
   - 界面主题深/浅槽切换 → 界面立即换色,另一槽不受影响
   - 终端主题深/浅槽切换 → 已开终端立即换配色
   - 字体下拉逐项切换 → 已开终端立即换字体,无右侧空白带
   - 字号/字重/行高改动 → 已开终端立即 refit,PTY 画面(TUI)不乱
   - 光标样式/闪烁 → 立即生效
   - shell 切换 → 新建会话用新 shell,已开会话不变
   - 回滚行数改小重建 → 往回翻行数受限且画面正常
   - Esc / ✕ / 完成 关闭均正常;重启后全部保持
