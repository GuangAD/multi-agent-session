# T5 终端即时生效接线

> 依赖:T2、T3、T4(settings-slice) | 对应:brief 第 2 节目标 5;spec 覆盖标准接缝五

## 实现方式

**干什么**:已开终端的外观全部改由解析函数驱动,设置变更即时应用到所有已开终端,度量变更触发 refit。

**输入**:settings-slice 的全量设置、系统深浅、已开终端注册表(use-terminal 既有)。

**处理**

1. `use-terminal.ts` 删除硬编码字体常量,openTerminal 的 options 改由 `resolveTerminalAppearance(settings, systemDark)` 展开构造;openTerminal 增加 settings 参数,调用方(TerminalView)从 slice 取。
2. 新增 `applyTerminalAppearanceToAll(settings, systemDark)`:遍历注册表逐终端 applyOptions,随后走既有 fit 路径(可见终端立即 fit,隐藏终端由 activateTerminal 既有机制补 fit)。
3. PTY 网格同步不改代码:fit 改变 cols/rows 后,既有 onResize → pty.resize 链路自动生效。
4. `App.tsx` 订阅 slice 设置与系统深浅 matchMedia,任一变化调用 applyTerminalAppearanceToAll;system 态终端主题随系统切换由这条路径覆盖。

**失败与退出**:解析不抛出;注册表为空时遍历空集,无副作用。

## 开发步骤

1. `use-terminal.test.ts` 追加用例 1(期望值来源:接线约定):注册两个 mock 终端,调 applyTerminalAppearanceToAll 后两个实例的 applyOptions 均被调、字体链来自解析输出。
2. 运行 `pnpm vitest run src/renderer/src/components/terminal/use-terminal.test.ts`;Expected: FAIL(exit 1),`1 failed`,红因是 applyTerminalAppearanceToAll 不存在。
3. 实现 applyTerminalAppearanceToAll;复跑;Expected: PASS(exit 0),既有条数 + `1 passed`,且不是 0 passed。
4. 追加用例 2 与用例 3(期望值来源:手算 / spec 接缝五):用例 2 断言 openTerminal 传入 fontSize=20 时新实例 options.fontSize === 20、字体链为解析链;用例 3 验证 applyToAll 的 systemDark 参数传递换槽——它测的是步骤 3 已实现的参数传递,预期直接绿,红阶段不适用。
5. 运行同命令;Expected: FAIL(exit 1),`1 failed`(用例 2 红,红因是 openTerminal 仍用常量;用例 3 应已绿)。
6. 改造 openTerminal 走解析输出后复跑;Expected: PASS(exit 0),既有条数 + `3 passed`,且不是 0 passed。
7. 运行 `pnpm typecheck`;Expected: exit 0。
8. 运行 `pnpm test`;Expected: exit 0,全绿。
9. 冒烟 `pnpm dev`:开两个终端标签;手改 store.json 字号 20 重启,两标签网格一致无右侧空白带;system 态下切换系统深浅,终端配色跟随。
