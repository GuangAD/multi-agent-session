# T3 终端主题数据与外观解析

> 依赖:T2 | 对应:brief 第 2 节目标 3、5;spec 覆盖标准接缝一(终端侧)、接缝二、接缝四

## 实现方式

**干什么**:把 Orca 22 套终端主题移植成本地目录数据,并提供字体预置清单与终端外观解析纯函数。

**输入**:设置对象(形状来自 T2)、系统深浅布尔、`.reference/orca-1.4.265` 的主题数据源文件。

**处理**

1. `catalog.ts` 按源文件逐套抄写色值,键用 Orca 原名,文件头标注移植来源。
2. `fonts.ts` 落默认回退链常量(从 use-terminal 现值原样搬)与 11 项预置清单。
3. `resolve.ts` 实现 selectTerminalTheme(三态 + 双槽 + 坏 id 兜底)与 resolveTerminalAppearance(字段独立映射 + 夹紧)。
4. 加粗字重不出设置:resolve 输出固定 fontWeightBold 500(现状值)。

**失败与退出**:纯函数不抛出;坏 id 落默认主题、越界值夹紧。

  systemDark: boolean
): { mode: 'dark' | 'light'; theme: ITheme }

  // 怎么用:纯函数,可重复调用;theme 字段永远可用(坏 id 落默认)

export function resolveTerminalAppearance(settings: Settings, systemDark: boolean): TerminalAppearance
  // 用途:设置 → xterm 全量外观,构造与运行时更新共用这一个来源
  // 怎么用:纯函数;输出可直接展开进 Terminal options
  // 出错时:不抛出;越界夹紧、坏枚举落默认值

## 数据结构(可选)

见 spec.md 数据结构节;catalog 完整性断言以下列 22 套名单为准:

深 13:Ghostty Default Style Dark、One Dark、Tokyo Night、Gruvbox Dark、Catppuccin Mocha、Solarized Dark、Material Dark、Ayu Dark、Rose Pine、Everforest Dark、Horizon Dark、Night Owl、Tango Dark
浅 9:Builtin Tango Light、Solarized Light、One Light、Catppuccin Latte、GitHub Light、Rose Pine Dawn、Gruvbox Light、Tokyo Night Light、Everforest Light

抄写源(`.reference/orca-1.4.265/src/shared/terminal-themes/`):`defaults.ts`(深浅默认)、`classic.ts`(Tango Dark)、`popular-dark-core.ts`(5)、`popular-dark-extended.ts`(6,源文件实含 10 套,契约名单取 6)、`popular-light.ts`(8)。

## 开发步骤

1. 建 `catalog.test.ts` 写完整性用例(期望值来源:上名单 + 色值格式约定),名单常量写进测试。
2. 运行 `pnpm vitest run src/shared/themes/catalog.test.ts`;Expected: FAIL(exit 1),`1 failed`,红因是 catalog.ts 尚不存在。
3. 抄写 defaults.ts + classic.ts + popular-dark-core.ts(共 8 套)进 catalog.ts,文件头标注移植来源。
4. 复跑步骤 2 命令;Expected: FAIL(exit 1),`1 failed`,红因变为缺 14 套(进度可断言)。
5. 抄写 popular-dark-extended.ts(名单内 6 套)+ popular-light.ts(8 套),共 14 套。
6. 复跑步骤 2 命令;Expected: PASS(exit 0),`1 passed`,且不是 0 passed。
7. 建 `fonts.ts`(回退链常量 + 11 项清单,清单见 brief 第 5 节)。
8. 建 `resolve.test.ts` 写接缝一终端侧用例 1-5(期望值来源:手算 + brief 第 5 节默认主题名)。
9. 运行 `pnpm vitest run src/shared/themes/resolve.test.ts`;Expected: FAIL(exit 1),`5 failed`,红因是 resolve.ts 尚不存在。
10. 实现 selectTerminalTheme;复跑;Expected: PASS(exit 0),`5 passed`,且不是 0 passed。
11. 写接缝二用例 6-10(期望值来源:手算 / brief 第 5 节边界 / 约定兜底)。
12. 运行同命令;Expected: FAIL(exit 1),`5 failed`,红因是 resolveTerminalAppearance 未实现。
13. 实现 resolveTerminalAppearance;复跑;Expected: PASS(exit 0),`10 passed`,且不是 0 passed。
14. 运行 `pnpm typecheck`;Expected: exit 0。
15. 运行 `pnpm test`;Expected: exit 0,全绿。
