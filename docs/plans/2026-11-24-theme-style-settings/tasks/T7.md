# T7 终端样式预览块

> 依赖:T6(对话框壳) | 对应:brief 第 2 节目标 6、验收 6;spec 整体实现第 4 步

## 实现方式

**干什么**:外观区顶部放一个迷你终端预览,如实反映主题与字体改动,自带深/浅切换钮(只切预览)。

**输入**:settings-slice 全量设置、resolveTerminalAppearance、移植的 ANSI 示例缓冲。

**处理**

1. 新建 `TerminalPreview.tsx`:创建独立 xterm 实例(36 列 × 15 行固定网格,disableStdin,不接 PTY,不参与 applyTerminalAppearanceToAll 的注册表)。
2. 选项来源:resolveTerminalAppearance(settings, previewDark);previewDark 是本地 state(初值 = 当前解析 mode),深/浅钮只改它。
3. 示例缓冲:移植 Orca `terminal-preview-content.ts` 的 ANSI 文本(文件头标注来源),初始化 write 一次;后续设置变化只 applyOptions,不重写缓冲。
4. 订阅 slice 设置变化重新 applyOptions;组件卸载即销毁实例。

**失败与退出**:实例创建失败不阻塞对话框其余控件,预览区显示占位文本;其余无失败路径。

## 开发步骤

1. 移植 `terminal-preview-content.ts`(源:`.reference/orca-1.4.265/src/renderer/src/components/settings/terminal/appearance/terminal-preview-content.ts`),36 列宽度下逐行核对不折行。
2. 实现 TerminalPreview(固定网格 + 解析选项 + 缓冲写入 + slice 订阅)。
3. AppearanceSection 顶部挂载,加深/浅切换钮(月/日图标,aria-label 标明「预览用,不改设置」)。
4. 运行 `pnpm typecheck`;Expected: exit 0。
5. 运行 `pnpm test`;Expected: exit 0,全绿。
6. 冒烟 `pnpm dev`(打开设置):
   - 改终端主题/字体/字号/字重/行高/光标 → 预览立即反映,与已开真实终端观感一致
   - 深/浅钮切换 → 预览切到另一槽主题;关闭重开设置,钮位回到当前解析态
   - 深/浅钮不改变标题栏三态与任何持久化值
   - 打开/关闭设置对话框 10 次,无实例泄漏(终端区无异常、内存无告警)
