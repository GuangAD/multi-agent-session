# T5 会话行分支小字与强制删除二次确认

> 依赖:T3、T4 | 对应:brief 第 2 节目标 8、第 5 节「会话行显示分支名」、第 6 节文案定稿

## 实现方式

**干什么**:让用户看得出哪条会话在 worktree 里,并给删除被挡住时一条出路。

**输入**:侧栏会话列表;删除确认框的点击。

**处理**

1. 会话行有 worktree 时,在标题下多一行分支名(与项目行的路径同一层级)。
2. 删除确认框点「删除」→ 调 `removeSession`。
3. 返回 `worktreeError` → 记录不删、第一个确认框换成显示 git 原文。
4. 弹「强制删除(丢弃未提交改动)」二次确认;点它才带 `forceWorktree` 再调一次。

**失败与退出**:二次确认取消 → 什么都不做,记录与目录都保留。任一步失败都只在确认框里显示原文,不弹系统对话框。

## 接口(伪代码)

落点:`src/renderer/src/store/sessions-slice.ts`

```ts
removeSession(
  id: SessionId,
  options?: { forceWorktree?: boolean }
): Promise<{ ok: true } | { ok: false; worktreeError: string }>
  // 用途:删会话,并告诉调用方是否被 worktree 里的改动挡住
  // 怎么用:ok 时记录已从列表移除、该关的标签页已关;失败时列表原样,可带 forceWorktree 重试
  // 出错时:不抛;桥接异常按通用失败回,列表不变
```
