# T4 侧栏入口与建 worktree 弹窗

> 依赖:T2 | 对应:brief 第 2 节目标 1/2、第 7.1 节第 1/4 条

## 实现方式

**干什么**:给侧栏加一个入口与一个弹窗,让建 worktree 变成点两下的事。

**输入**:项目行「更多」按钮;弹窗里用户选的起点分支、名称、agent。

**处理**

1. 打开「更多」菜单时探一次仓库根(`worktree.isRepoRoot`),不是仓库根就不渲染这一项。
2. 点该项 → 写弹窗描述(目标项目)→ 弹窗挂载时取本地分支列表(既有 `git.branches`)。
3. 点某个 agent → 调 `worktree.create` → 成功才关弹窗(失败保持打开,见「处理 5」;实现期把原稿的「先关再调」纠正为此序)。
4. 成功 → 记录入 store、开标签页、登记待 spawn(目录取 worktree 路径)。
5. 失败 → 弹窗保持打开,把 failure 与 detail 显示出来。

**失败与退出**:创建失败不改 store、不开标签页。弹窗内错误文案按 brief 第 6 节在 T5 定稿。

  project: Project,
