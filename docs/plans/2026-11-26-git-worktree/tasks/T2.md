# T2 worktree 建链路(后端到记录)

> 依赖:T1 | 对应:brief 第 2 节目标 3/5/6、spec 覆盖标准 1/2/3/8/9/11

## 实现方式

**干什么**:把「建一个 worktree」做完——校验、判定、执行 git、记排除、写会话记录。

**输入**:项目 id、名称、起点分支、agent id(来自桥接);项目路径、会话记录(主进程自取)。

**处理**

1. 名称校验不通过 → 直接回 `name-invalid`,一条 git 命令都不执行。
2. 取三样事实:目标目录是否存在(`fs`)、git 已登记的路径(`worktree list`)、已有会话占用的路径(store)。
3. 冲突判定命中 → 回对应 failure;否则执行 `worktree add -b`。
4. 成功后把 `.worktree/` 幂等追加进 `.git/info/exclude`,写失败只记日志。
5. 写会话记录:worktree 三项、agent 归一后的 id、标题取 agent 显示名。

**失败与退出**:git 抛错时回 `git-error` 并带原文,不落记录、不删已建目录(目录属用户产物,交给人工)。
