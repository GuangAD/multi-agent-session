# T1 会话运行目录与面板跟随

> 依赖:无(前置改动) | 对应:brief 第 2 节目标 9、第 5 节「面板跟随」、spec 覆盖标准 6/7/13/14

## 实现方式

**干什么**:把「会话在哪个目录里运行」收成唯一来源,并让右栏面板按这个来源取值。

**输入**:会话记录(可选带 worktree)、所属项目、侧栏选中项目。

**处理**

1. `Session` 增加可选 worktree 三项,读写语义暂无人使用。
2. `resolveSessionDir` 按「有 worktree 用 worktree 路径,否则用项目路径」给出运行目录。
3. `resolvePanelRoot` 取活动会话的运行目录;没有活动会话或所属项目已删时用选中项目。
4. `App` 算出目录,下传文件树与 Git 面板;「在 VS Code 打开」用同一份。

**失败与退出**:两者都是纯函数,不会失败。目录为空(`null`)时由面板显示既有空态。

## 接口(伪代码)

落点:`src/shared/session-dir.ts`

```ts
resolveSessionDir(session: Session, project: Project): string
  // 用途:给出这条会话的运行目录——终端 cwd、面板根、后续 spawn 都取它
  // 怎么用:纯函数,可重复调用;项目必须是该会话所属项目,传错项目会得到错误的回落路径
  // 不会失败:没有 worktree 就是项目路径
```

落点:`src/renderer/src/panel-root.ts`

```ts
resolvePanelRoot(input: {
  activeSession: Session | null
  activeProject: Project | null // 活动会话所属项目;项目被移除后可能为 null
  selectedProject: Project | null
}): string | null
  // 用途:决定右栏面板显示哪个目录
  // 怎么用:纯函数;活动会话与项目都在场才用会话目录,否则回落选中项目,null = 空态
  // 不会失败
```
